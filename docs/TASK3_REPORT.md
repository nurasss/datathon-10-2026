## G. Что не сделано / ограничения

- **OUTSIDER не доведён до приёмки:** FP, пропуски, ранние начала; отсутствует
  надёжное различение штатного клиента и доступа в служебную зону. Нужны
  проверенные границы зон, более устойчивые роли/действия и обработка доступа рукой.
- **Триггеры ухода/входа и роли недостаточны даже при идеальной сцене** — это
  видно по scene-only oracle, а не скрывается ожиданием модуля другого агента.
  Стабильность ID проверена синтетикой, датасетной разметки ID для оценки нет.
- Визуальный `scene_state` **не реализовывался намеренно**, согласно разделению
  работы. Во всём финальном прогоне состояния неизвестны, зависимые правила
  молчат. Источник: `artifacts/report/integrity.json → scene_stub_videos`.
- Не доказана неухудшаемость person на всех кадрах/каждом видео: аудит разреженный,
  на Х-18 есть уменьшение числа боксов; число боксов не заменяет person-разметку.
- Нет подтверждённой дельты к baseline задачи 2: исходные артефакты не переданы.
- Нет проверки на изолированном Linux-сервере с целевыми ресурсами. Замеры
  выполнены на общем Mac; характеристики сохранены в `artifacts/provenance/environment.json`.
- Чужие worktree не изменялись, основной сервер не перезапускался; модуль другого
  агента не переносился. Нагрузка и полный evaluate после получения результата
