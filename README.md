# Forte Vision — материалы хакатона

Ветка с материалами вне кода сервиса (код — в ветке `backend`).

| Папка | Что внутри |
|---|---|
| `presentation/` | Питч (PDF, PPTX), заметки спикера, скрипт сборки |
| `brag-output/` | Промо-ролик и исходники композиции |
| `models_colab/` | Эксперименты в Colab: дообучение YOLOX-nano, разметка через Qwen, сравнение (в финальную версию не вошли). Веса и разметка не публикуются — они получены из данных организатора |
| `norms/` | Черновик реестра норм |
| `SUBMISSION.md` | Заметки по сдаче |

Ветки кода: `backend` (финальная сдача), `feat/core`, `feat/scene`, `feat/infra`, `integ` (интеграция, не вошла в сдачу), `frontend`.
